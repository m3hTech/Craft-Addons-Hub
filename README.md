# Craft Addons Hub

Craft Addons Hub is a mobile application currently in early development, focused on helping Minecraft Bedrock players discover add-ons, maps, texture packs, and other community-created content more easily.

The project is being built as a mobile-first discovery experience with features such as:

- Add-on browsing
- Search
- Categories
- Curated collections
- Compatibility information
- Favorites
- Add-on detail pages
- Download integration for supported content

## Current Status

The project is currently in the MVP / prototype stage.

The user interface and core navigation are being developed using local mock data.

There is currently no CurseForge API integration in the application.

CurseForge API integration will be implemented only after API access is approved.

## Planned CurseForge Integration

If API access is granted, CurseForge will be used as one of the content sources for Minecraft Bedrock projects.

The application will:

- Use the official CurseForge API
- Respect mod authors' third-party distribution preferences
- Clearly credit original authors
- Identify CurseForge as the source where applicable
- Use official download URLs provided by the API
- Avoid unauthorized re-hosting of CurseForge files
- Link users to the original CurseForge project when appropriate

The goal of the application is not to mirror CurseForge, but to provide a mobile-focused discovery experience with improved categorization, compatibility information, curated recommendations, and a simplified experience for Bedrock players.

## Monetization

The application may use non-intrusive mobile advertising in the future.

An optional one-time purchase to remove advertisements may also be considered.

Community-created add-ons themselves will not be sold or placed behind a paywall.

## Technology

Planned stack:

- React Native
- Expo
- JavaScript / TypeScript
- CurseForge API
- Additional Bedrock content sources may be evaluated in the future

## Development Stage

This repository represents an early-stage project.

Features, architecture, branding, and integrations may change during development.

API integrations will only be added after the required permissions and access are obtained.
